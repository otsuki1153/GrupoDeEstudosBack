# Grupo De Estudos Back End SENAC
Este repositório reúne códigos, exemplos práticos e exercícios desenvolvidos durante o grupo de estudos com foco em desenvolvimento Back-End da Faculdade Senac Portão.

🎯 Objetivo

O principal objetivo deste repositório é servir como base de aprendizado colaborativo, permitindo que os participantes:

Pratiquem conceitos fundamentais de Back-End
Compartilhem soluções e diferentes abordagens
Acompanhem a evolução técnica ao longo do tempo
Tenham um material de apoio organizado para revisões futuras

🧠 Proposta do Repositório

O repositório tem como foco o desenvolvimento Back-End, porém com uma abordagem ampla e flexível.

Isso significa que diferentes áreas dentro do Back-End podem ser exploradas ao longo do tempo, de acordo com a evolução do grupo de estudos.

Os conteúdos abordados podem variar entre fundamentos, práticas de desenvolvimento e conceitos mais avançados, sempre com o objetivo de fortalecer o conhecimento técnico e a capacidade de resolução de problemas.

O foco está no aprendizado contínuo, na experimentação e na construção de uma base sólida em desenvolvimento Back-End.

📂 Estrutura do Repositório

A organização dos arquivos segue uma estrutura simples para facilitar o entendimento:

/NomeDoParticipante
    /TemaOuAula/
        arquivo.ext

Exemplo:

/Henrique
    /ServidorHTTP/
        server.js

🚀 Como Executar os Projetos
Clone o repositório:
git clone <url-do-repositorio>

Acesse a pasta desejada:
cd NomeDoParticipante/TemaOuAula

Execute o projeto conforme a tecnologia utilizada
(exemplo com Node.js):

node arquivo.js
